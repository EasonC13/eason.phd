One thing that keeps many blockchain applications from reaching normal users is not the core functionality, but the onboarding friction.

This project line focuses on **consumer-facing blockchain UX**, especially how to remove the two biggest early barriers: wallet setup and transaction fees.

## What this project direction is about

- **zkLogin** lets users create and access wallets through familiar OAuth accounts.
- **Sponsored transactions** remove the need to preload gas before trying an app.
- **Application-level UX design** turns those technical primitives into smoother first-use experiences.

## Why I think this matters

I care about blockchain systems not only as protocols, but as products people can actually use.

If onboarding is too confusing, even a technically elegant system will remain niche. This line of work looks at how infrastructure design and interface design can work together to make blockchain applications far easier to adopt.
