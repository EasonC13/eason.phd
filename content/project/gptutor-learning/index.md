GPTutor started as an AI-assisted programming tool for code explanation and review. Over time, this project direction expanded into a broader research agenda on **personalized learning systems** built with generative AI.

Rather than treating LLMs as one-size-fits-all chatbots, this work explores how they can adapt explanations, examples, exercises, and support to match a learner's goals and interests.

## What this project direction covers

- **AI pair programming and code understanding**, starting from the original GPTutor extension.
- **Personalized learning content generation**, where GPTutor creates tailored educational materials for different learners.
- **Adaptive learning with generative AI**, connecting modern LLM systems to longer-standing ideas in learning sciences.

## Why I grouped these papers together

Although these papers have different scopes, they all ask a similar question: **how can generative AI become a practical learning partner instead of just a flashy assistant?**

This line of work moves from developer tooling toward personalized educational systems, while keeping the same core motivation, making hard things easier to learn.
