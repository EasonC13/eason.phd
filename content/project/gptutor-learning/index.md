This project cluster covers my recent work on **GPTutor** as it evolved from a code-explanation tool into a broader family of personalized learning systems.

The line of work includes:

- **GPTutor for code explanation and pair programming**, including open-source tooling that helps learners understand and improve code in context.
- **Personalized learning content generation**, where GPTutor adapts examples and exercises to a learner's interests and goals.
- **Bridging GenAI with adaptive learning**, connecting large language models to long-standing ideas in learning sciences and educational personalization.

Together, these projects explore how generative AI can move beyond generic chatbot interactions and become a practical educational partner for learning, practice, and feedback.
