This project cluster brings together my recent work on **multimodal educational feedback**.

Instead of treating feedback as plain text only, these systems explore richer forms of support:

- **VTutor**, an open-source SDK for animated pedagogical agents with synchronized speech, expressions, and web deployment.
- **SlideItRight**, which retrieves relevant lecture slides alongside AI-generated feedback for open-ended questions.
- **Avalon**, a human-in-the-loop grading workflow that calibrates LLM grading with instructors and student self-assessment.
- **MuFIN**, a framework for automating multimodal feedback generation with generative AI.

Across these systems, the goal is the same: make AI feedback more trustworthy, more engaging, and more useful at classroom scale.
